Privacy-X Web Status
====================

বর্তমানে Privacy-X প্রোজেক্টে কোনো Web অ্যাপ (HTML/CSS/JavaScript/React) তৈরি করা নেই।
এই প্রোজেক্টটি সম্পূর্ণরূপে একটি Native Android অ্যাপ (Kotlin + Jetpack Compose)।

তাই:
- এখানে কোনো Web অ্যাপ ফাইল নেই এবং কোনো পাবলিক ওয়েব লিংক তৈরি করা সম্ভব হয়নি।
- ভবিষ্যতে যদি আপনি এই একই Firebase (privacy-x) ও Supabase (chat-media) ব্যাকএন্ড ব্যবহার করে Web ভার্সন বানাতে চান, তখন Web ফাইলগুলো এই ফোল্ডারে রাখা যাবে।
